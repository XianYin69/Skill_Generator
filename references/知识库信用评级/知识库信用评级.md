# 知识库信用评级

对知识库来源按维度打分（0–5），加权得出等级，决定是否入库与引用方式。
用于 [知识库构建](../../branch/流程/知识库构建/知识库构建.md) 的文献筛选环节。

## 允许的来源类型

1. 开放文献数据库（arXiv、PubMed、DOAOA、开放获取期刊）。
2. 百科全书（Wikipedia 等，须经二次核验）。
3. 权威论坛与博客（领域公认作者、长期稳定维护）。
4. 使用 MIT 许可证的仓库（GitHub/GitLab 等）。

## 评分维度

| 维度 | 说明 | 权重 |
|---|---|---|
| 权威性 | 作者/机构声誉、同行评审 | 0.25 |
| 时效性 | 发布/更新时间是否够新 | 0.15 |
| 可核验 | 是否给出可复现依据/链接 | 0.20 |
| 许可合规 | 许可证明确且允许再分发（优先 MIT） | 0.20 |
| 普适性 | 是否行业通用、非个案 | 0.20 |

## 等级

- A（≥4.0）：直接入库。
- B（3.0–3.9）：需辩论测试（正反）后入库。
- C（2.0–2.9）：仅作线索，须找更优来源。
- D（<2.0）：拒用。

## 合规硬性要求

- 保留许可证与版权信息（见 `.provenance.json`）；许可缺失或不合规直接判 D。
- 元数据须清洗后转为目标 skill 适配条目（json/md/svg）。
