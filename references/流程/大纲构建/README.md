# 大纲构建

基于查询到的经验材料，构建并审阅初步流程大纲。

## 步骤

1. 解析词条间关联，检查是否存在关系错乱。
   - 存在 → 重新查询，回到 [经验查询](../经验查询/)
   - 不存在 → 进入下一步
2. 检查能否形成初步流程大纲。
   - 不能 → 回到 [经验查询](../经验查询/) 继续查询
   - 能 → 生成《初步流程大纲》，写入 `tmp/outline.md`
3. 审阅大纲：
   - 是否可执行？否 → 记录错误点及上下文，联网搜索解决方案（见下文）
   - 是否可到达每个路径？否 → 同上
   - 是否有兜底机制和错误回避机制？否 → 同上
4. 搜索解决方案后修改大纲，重新审阅，循环直至通过。
5. 将大纲提交用户，询问是否接受。
   - 不接受 → 记录修改意见，回到 [经验查询](../经验查询/) 重新查询
   - 接受 → 生成最终流程大纲，进入 [分支分析](../分支分析/)

### 联网搜索解决方案

- 记录未找到的问题点
- 搜索后若找到方案 → 修改大纲，重新审阅
- 未找到 → 向用户询问期望方案，再搜索，循环

## 决策点

- 词条有关联？（否 → 重查）
- 可形成大纲？（否 → 重查）
- 可执行/可达/有兜底？（否 → 搜方案修改）
- 用户接受？（否 → 重查）
