# 收尾

完成最终收尾工作：安装脚本、提示词、自更新模块、文档编辑、git 提交。

## 步骤

1. 联网搜索 Skill 用途，记录关键信息。
2. 编写用户 Skill 安装脚本，存入 `scripts/`。
3. 整合角色提示词：
   - 审核提示词是否通过
   - 否 → 跳回 [整体审查](../整体审查/整体审查.md) 重新审查
   - 是 → 标记「提示词编写完成」
4. 编写自更新模块：
   - 审核是否通过
   - 否 → 跳回 [整体审查](../整体审查/整体审查.md)
   - 是 → 标记「自更新模块编写完成」
5. 编辑 README、CHANGELOG、LICENSE（遵守 `rule_edit.md`）。
6. 执行 git 操作：提交、推送。
7. 执行收尾清理，标记「Skill 开发完成」。
8. 写入 `tmp/progress.md` 最终状态。

## 终止节点

标记「完成 Skill 开发」，流程结束。
