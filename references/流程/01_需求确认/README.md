# 01_需求确认

确认用户需求，并判断后续路径（创建 or 修改）。

## 步骤

1. 收集用户输入，理解其目标。
2. 判断需求类型：
   - 创建新 Skill → 进入 [02_经验查询](../02_经验查询/)
   - 修改已有 Skill → 进入 [10_修改流程](../10_修改流程/)
3. 建立《用户需求表》，记录：
   - 目标：Skill 要解决什么问题
   - 功能：需要哪些核心能力
   - 约束：格式、长度、语言等限制
   - 期望输出：最终交付物形态
4. 将需求表写入 `tmp/requirement.md`。

## 决策点

- 需求是否明确？（否 → 提问；是 → 判断类型）
- 创建还是修改？（创建 → 02；修改 → 10）
