# 整体审查

按九项标准对成品 Skill 进行全面审核。

## 审查九项标准

逐项检查项目是否满足：
1. **安全性**：无泄露敏感信息风险
2. **完整性**：所有步骤均有定义
3. **实用性**：可实际运行，非理论空转
4. **适用性**：适用于目标场景
5. **可拓展性**：新增需求可平滑接入
6. **可维护性**：结构清晰，易于后续修改
7. **易用性**：用户操作路径简洁
8. **可达性**：所有分支均可到达
9. **健壮性**：异常情况下有降级策略

任一不通过 → 记录未通过项，跳回对应步骤修复，然后进入循环审核。

## 循环审核

修复后依次检查：
1. 模型是否可以流畅使用？否 → 跳回对应步骤
2. 是否可以流畅运行？否 → 跳回对应步骤
3. 是否符合文件编写规范？否 → 跳回对应步骤
4. 是否满足最小化原则？否 → 跳回对应步骤

全部通过 → 进入 [收尾](../收尾/收尾.md)。

## 决策点

- 九项标准通过？（否 → 跳步修复）
- 模型流畅？（否 → 跳步）
- 运行流畅？（否 → 跳步）
- 符合规范？（否 → 跳步）
- 最小化？（否 → 跳步）
