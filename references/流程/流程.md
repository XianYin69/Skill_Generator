# 流程（Process）

本目录存放 Skill_Generator 的执行流程细则，每个步骤独立成文件夹（或文件）。

## 两条独立路径

创建与修改是两条完全独立的流程，各自从「初始化」开始，互不交织。

### 创建流程

```
[初始化/](初始化/) → [需求确认/](需求确认/) → [经验查询/](经验查询/) →
[大纲构建/](大纲构建/) → [分支分析/](分支分析/) → [脚本构建/](脚本构建/) →
[知识库构建/](知识库构建/) → [约束编写/](约束编写/) → [整体审查/](整体审查/) →
[收尾/](收尾/) → 完成
```

完成收尾后，创建流程结束。

### 修改流程

```
[初始化/](初始化/) → [修改流程/](修改流程/) → 完成
```

修改流程独立运行，结束后标记「完成项目修改」。

## 步骤列表

| 步骤 | 路径 | 说明 |
|---|---|---|
| 初始化 | [`初始化/`](初始化/) | 建立工作空间，两条路径的共同前置步骤（含子节点见 [`初始化/README.md`](初始化/)） |
| 需求确认 | [`需求确认/`](需求确认/) | 确认需求，区分创建 or 修改 |
| 经验查询 | [`经验查询/`](经验查询/) | 联网查询相关领域经验 |
| 大纲构建 | [`大纲构建/`](大纲构建/) | 构建并审阅初步流程大纲 |
| 分支分析 | [`分支分析/`](分支分析/) | 分析各分支约束与逻辑 |
| 脚本构建 | [`脚本构建/`](脚本构建/) | 编写并审核脚本 |
| 知识库构建 | [`知识库构建/`](知识库构建/) | 搜索并验证知识库文献 |
| 约束编写 | [`约束编写/`](约束编写/) | 编写与合并约束规则 |
| 整体审查 | [`整体审查/`](整体审查/) | 九项标准整体审查 |
| 收尾 | [`收尾/`](收尾/) | 收尾、提示词、自更新、git |
| 修改流程 | [`修改流程/`](修改流程/) | 修改已有 Skill 的流程（独立，不接在收尾之后） |
