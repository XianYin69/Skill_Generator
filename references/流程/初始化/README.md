# 初始化（根节点）

在执行任何操作前，必须先完成初始化。创建与修改两条路径均从这里开始。

## 流程总览

```
[01_读取目录] → [02_判断目录] → [03_检查tmp] ──是──→ [09_标记完成]
                                    ↓ 否
                               [04_记录目录] → [05_切换目录] → [06_检查切换] → [07_检查用户tmp]
                                                                                      ↓ 无
                                                                                 [08_建立tmp] → [09_标记完成]
```

## 步骤节点

| 步骤 | 节点 | 说明 |
|---|---|---|
| 入口 | [01_读取目录](./01_读取目录.md) | 读取当前目录 且 询问用户工作空间目录 |
| 判断 | [02_判断目录](./02_判断目录.md) | 判断当前目录与用户指定目录是否一致 |
| 当前检查 | [03_检查tmp](./03_检查tmp.md) | 检查当前目录是否存在 tmp 文件夹 |
| 记录 | [04_记录目录](./04_记录目录.md) | 记录用户指定目录 |
| 切换 | [05_切换目录](./05_切换目录.md) | 切换到用户指定目录（无法切换则提示用户） |
| 切换验证 | [06_检查切换](./06_检查切换.md) | 是否成功切换到用户指定目录 |
| 用户目录检查 | [07_检查用户tmp](./07_检查用户tmp.md) | 检查用户指定目录是否存在 tmp 文件夹 |
| 建立 | [08_建立tmp](./08_建立tmp.md) | 建立 tmp 文件夹及其他初始文件夹 |
| 完成 | [09_标记完成](./09_标记完成.md) | 标记初始化完成，返回检查用户需求 |

## 后续路径

完成初始化后，进入 [需求确认](../需求确认/) 或 [修改流程](../修改流程/)。
