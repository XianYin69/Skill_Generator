# 初始化

在执行任何操作前，必须先完成初始化。创建与修改两条路径均从这里开始。

## 步骤

1. 读取当前目录。
2. 询问用户工作空间目录。
3. 判断当前目录与用户指定目录是否一致：
   - 一致 → 检查是否存在 `tmp/`，无则建立 `tmp/` 及其他初始文件夹（`references/`、`scripts/`、`branch/`、`update/`、`resistance/`）。
   - 不一致 → 记录用户指定目录，尝试切换；切换失败则提示用户手动切换。
4. 标记「初始化完成」，写入 `tmp/progress.md`。
5. 进入下一步：根据用户需求判断后续路径。

## 决策点

- 目录是否一致？（否 → 切换或提示）
- 是否成功切换？（否 → 提示用户手动操作）
- 是否需要建立初始文件夹？（否 → 提示用户检查路径权限）
