# 02_经验查询

联网查询相关领域经验，为大纲构建提供素材。

## 步骤

1. 联网分条查询相关领域经验。
2. 记录搜索结果：网址、关键词出现次数。
3. 判断是否可以查到足够经验。
   - 可查到 → 进入 [03_大纲构建](../03_大纲构建/)
   - 查不到 → 进入兜底逻辑

### 兜底逻辑

1. 向用户询问相关经验网址或关键字。
2. 用户是否提供？
   - 是 → 用用户提供信息重新查询，回到步骤 1
   - 否 → 检查重试次数是否超过 10 次
     - 未超 → 继续重试
     - 超过 → 启动**联网漫游**，抓取潜在提示词后交用户确认

## 决策点

- 能否查到经验？（否 → 兜底）
- 用户是否提供信息？（否 → 超 10 次则漫游）
