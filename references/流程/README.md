# 流程（Process）

本目录存放 Skill_Generator 的执行流程细则，每个步骤独立成文件夹。

## 入口顺序

```
初始化 → 01_需求确认 → 02_经验查询 → 03_大纲构建 → 04_分支分析 →
05_脚本构建 → 06_知识库构建 → 07_约束编写 → 08_整体审查 → 09_收尾
                                    ↓
                         （修改路径）→ 10_修改流程
```

**无论创建还是修改，第一步均为「初始化」。**
