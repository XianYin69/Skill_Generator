# 流程（Process）

本目录存放 Skill_Generator 的执行流程细则，每个步骤独立成文件夹。

## 两条独立路径

创建与修改是两条完全独立的流程，各自从「初始化」开始，互不交织。

### 创建流程

```
初始化 → 需求确认 → 经验查询 → 大纲构建 → 分支分析 →
脚本构建 → 知识库构建 → 约束编写 → 整体审查 → 收尾
```

完成「09_收尾」后，创建流程结束。

### 修改流程

```
初始化 → 10_修改流程
```

修改流程独立运行，结束后标记「完成项目修改」。

## 步骤列表

| 步骤 | 路径 | 说明 |
|---|---|---|
| 初始化 | [`初始化/`](初始化/) | 建立工作空间，两条路径的共同前置步骤 |
| 需求确认 | [`需求确认/`](需求确认/) | 确认需求，区分创建 or 修改 |
| 02–09 | 各步骤文件夹 | 创建流程各阶段 |
| 修改流程 | [`修改流程/`](修改流程/) | 修改流程（独立，不接在收尾之后） |
