# 脚本构建

依据脚本功能描述表编写、审核 Python 脚本。

## 步骤

1. 读取 `tmp/` 目录下所有文件。
2. 联网搜索所需交互操作和逻辑操作的相关资料。
   - 可搜索到 → 进入下一步
   - 不可搜索到 → 向用户询问相关问题，用户提供后重新搜索
3. 建立《脚本功能描述表》与《脚本-流程索引表》，写入 `tmp/scripts_index.md`。
4. 依据描述表编写 Python 脚本，存入对应目录。
5. 审核脚本：
   - 是否存在 Bug？是 → 修复后重新审核
   - 功能是否与描述一致？否 → 修改后重新审核
   - 索引是否正确？否 → 修改索引文件后重新审核
6. 全部通过后，标记「脚本构建完成」，写入 `tmp/progress.md`。
7. 进入 [知识库构建](../知识库构建/知识库构建.md)。

## 决策点

- 能否搜索到资料？（否 → 问用户）
- 脚本有 Bug？（是 → 修复）
- 功能匹配描述？（否 → 修改）
- 索引正确？（否 → 修改索引）
