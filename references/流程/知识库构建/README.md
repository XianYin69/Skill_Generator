# 知识库构建

联网搜索相关领域文献，构建知识库并验证有效性。

## 步骤

1. 联网搜索相关领域文献。
   - 可搜索到 → 进入下一步
   - 不可搜索到 → 记录未找到的知识，向用户询问
2. 用户是否提供相关文献？
   - 是 → 用用户提供文献，回到步骤 1
   - 否 → 启动联网漫游兜底
3. 对找到的文献进行正反辩论测试：
   - 是否通过辩论？否 → 重新搜索，回到步骤 1
   - 是 → 进入下一步
4. 是否可用于整个行业？否 → 重新搜索，回到步骤 1
5. 建立《知识文献与流程步骤索引表》，写入 `tmp/knowledge_index.md`
6. 标记「知识库构建完成」，写入 `tmp/progress.md`
7. 进入 [约束编写](../约束编写/)。

## 决策点

- 能找到文献？（否 → 问用户/漫游）
- 通过辩论？（否 → 重搜）
- 可行业通用？（否 → 重搜）
