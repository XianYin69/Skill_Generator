# 逻辑链机制（约束）

> 适用：大纲构建、分支分析、整体审查等所有推理型步骤。

## 红线

1. 禁止跳步：每步须有明确「前提→结论」，前一步结论=后一步前提。
2. 无据推断视为缺陷，整体审查不通过并跳回。
3. 决策分支必须标注触发条件（是/否/接受…），不得隐含。

## 校验

- 记录为 JSONL，逐链校验连续性；断裂即熔断并要求补链。

## 正反双链辩论（审核强制）

审核类步骤（整体审查、收尾审核提示词、知识库正反辩论）各须做一次双链辩论：
1. 建**正方链**（支持当前结论/通过）与**反方链**（质疑、找反例）两条独立逻辑链。
2. 两链各自 `verify`；任一方断裂即判该方败。
3. 据有效步数裁决：`debate` 输出「通过/不通过/平链转人工」。
4. 平链或反复失败按[惩罚机制](../惩罚机制/惩罚机制.md)计数熔断。

## 执行入口

脚本 [`scripts/logic_chain.py`](../../scripts/logic_chain.py)：`add` / `verify` / `debate --pro --con`。
