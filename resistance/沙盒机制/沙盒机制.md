# 沙盒机制（约束）

> 适用：用户未指定目标工作目录时，Skill_Generator 的临时工作区建立与收尾交付。

## 红线

1. 未指定目标工作目录时，必须在固定路径（env `SG_SANDBOX_HOME` → 用户缓存目录 → 用户根，统一 `Skill_Generator/sandbox/`）建沙盒作业；禁止直接在当前目录或磁盘根创建工程。
2. 沙盒须在收尾交付：询问用户目标工作区路径，预览确认后 `deliver --yes` 复制；禁止静默使用默认路径或猜测目标。
3. 交付校验成功前不得删除沙盒；失败/中断必须保留沙盒并记 process_chain，供 resume 重交付。
4. 目标路径非空时拒绝覆盖，须由用户更换路径或显式接管。
5. 沙盒内禁止存放凭证与个人敏感文件；交付后沙盒必须清理，不留残。

## 降级动作

- 固定路径不可写 → 询问用户目标目录，转常规路径（记录目录 → 切换目录）。
- 删除失败 → 报告沙盒路径交用户处理，不循环重试（受惩罚机制约束）。

## 执行入口

脚本 [`scripts/sandbox.py`](../../scripts/sandbox.py)；流程节点：[建立沙盒](../../branch/流程/初始化/建立沙盒/建立沙盒.md)、[沙盒交付](../../branch/流程/收尾/沙盒交付/沙盒交付.md)。
