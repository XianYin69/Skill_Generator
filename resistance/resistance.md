# resistance（约束库 / 兜底库）

本目录存放本 Skill 不可逾越的规则、红线、异常降级策略。

## 应存什么

- 「必须 / 禁止」类的约束（自然语言、每条 ≤ 50 行）。
- 执行期触发兜底（fallback）的条件与降级动作。
- 与外部系统的交互边界。

## 当前内容

- [`rule_edit.md`](../rule_edit.md)：skill 本体编辑规则（已在上层，本目录保留引用）。
- [`git工作流约束/`](git工作流约束/git工作流约束.md)：每步功能分支提交、双链辩论→合入 dev、九项审查通过→合入 main 并推送的分支策略。
- [`约束部分/`](约束部分/约束部分.md)：受约束「红线区」的识别规则。
- [`审查约束/`](审查约束/审查约束.md)：整体审查得出的项目级约束条件。
- 五大机制约束：[`垃圾回收机制`](垃圾回收机制/垃圾回收机制.md)、[`上下文压缩机制`](上下文压缩机制/上下文压缩机制.md)、[`逻辑链机制`](逻辑链机制/逻辑链机制.md)、[`过程链存取`](过程链存取/过程链存取.md)、[`惩罚机制`](惩罚机制/惩罚机制.md)。

## 遵守原则

1. 修改本目录内的约束前必须先通过 [update 审批流](../update/update.md)。
2. 违反本目录内容的操作不得执行，除非有显式兜底方案覆盖。
3. 本目录变更必须记录到 [`CHANGELOG.md`](../CHANGELOG.md) 并注明违反后果。
