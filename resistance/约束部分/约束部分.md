# 约束部分（Constrained Sections）

> **状态：规划中，尚未实现。**

本文件将规定 Skill_Generator 在编辑 / 生成内容时对「约束部分」的处理规则：
- 哪些区域属于受约束的「红线区」，不允许 Agent 或脚本自由修改。
- 受约束区域的版本保护策略（只读 / 签名校验）。
- 与 [`resistance/`](../resistance.md) 的关系：本文件管「区域识别」，`resistance/` 管「越界后的降级动作」。

预期子条目（按主题分节）：
1. `rule_edit.md` — 已纳入本约束清单。
2. `SKILL.md` 子模块索引 — 索引项增删需保留历史痕迹。
3. `flowchart/index.json` — 结构变更需经 `branch/` 审批。
4. **本体修改限制**：本 skill（`Skill_Generator`）自身的所有文件（`SKILL.md`、`scripts/`、`branch/`、`resistance/`、`update/`）**只允许通过 [`self_update` 接口](../../update/update.md) 修改**；禁止 Agent 直接对 skill 本体写盘。任何变更必须在 `tmp/` 镜像中准备，再经由 `compare → release` 覆盖生效。

详见 [`FILE_CREATION_POLICY.md`](../../FILE_CREATION_POLICY.md) 与 [`rule_edit.md`](../../rule_edit.md)。
