# 垃圾回收机制（约束）

> 适用：本 Skill 与所有生成的目标 skill 的工作区 `tmp/`。

## 红线

1. 目标 skill 目录内不得残留 `.tmp/.bak/.log/.part` 等临时文件。
2. `tmp/` 只作暂存；收尾比对释放后必须删除，不得随 skill 发布。
3. 下载素材超过保留期（默认 3 天）未转正的，回收清除。
4. 禁止删除已被 `.provenance.json` 引用的原始文件（版权留证）。

## 降级动作

- 回收前以 `--dry-run` 预览；异常时保留文件并上报，不静默删除。

## 执行入口

脚本 [`scripts/garbage_collect.py`](../../scripts/garbage_collect.py)。
