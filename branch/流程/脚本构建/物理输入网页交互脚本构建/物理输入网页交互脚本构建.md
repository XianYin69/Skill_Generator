# 物理输入/网页交互脚本构建

读取需求表中记录的物理输入/网页交互脚本清单，编写对应脚本。

## 步骤

1. 读取 `tmp/requirement.md`，检查是否需要以下脚本：
   - `vision_input.py`：视觉输入（摄像头/截图/图像识别）
   - `audio_input.py`：听觉输入（麦克风/音频识别）
   - `browser_interaction.py`：网页交互（Playwright/Puppeteer）
2. 对每个需要脚本的类型：
   - 联网搜索最佳实践和 API。
   - 建立脚本描述（参数、返回格式、依赖许可）。
   - 编写脚本，存于 `scripts/`，使用英文名称。
   - 依赖须为 MIT 许可证。
   - 脚本 ≤ 50 行。
3. 全部完成后进入下一步。
