# 依赖必须附原始链接

脚本构建确定依赖后执行：每条依赖必须登记**原始链接**，否则判不合格。

## 操作步骤

1. **网页检索定位原始仓库**：对每条依赖（软件/库/仓库/技能）联网检索其 GitHub/GitLab/官方仓库或发布页原始链接；不得用镜像、文档站或搜索跳转链接代替。
2. **写入 `dependence/deps.json`**：`dependencies` 数组，每条字段固定为
   `name / source_url / license / version / install / checked_at`（可选 `source_url_status: verified|unverified`）。
   - `source_url`：原始链接；本地技能依赖写 `local://<skill-id>`。
   - `checked_at`：本地 ISO 时间；核实过填 `verified`，核不了填 `unverified`（不得留空链接）。
3. **lint 校验**：`python -B scripts/lint-deps.py --root <工作空间>`——缺 `source_url` 或字段不全即报错退出（rc=1），必须补齐后重跑。
4. **同步 `dependence/dependence.md`**：人读清单与 `deps.json` 条目一一对应。

## 与 SMS 的接口

SMS 安装/净化时按 `deps.json` 的 `source_url` 联网检索或下载到技能目录（须 `:grant network` 与下载确认）；
无原始链接的依赖无法追溯来源，一律拒装。

## 分支

- **检索不到原始链接** → 记 `process_chain.py interrupt`，向用户求证来源；确无来源则移除该依赖，禁止填占位链接。
- **lint 不通过** → 回「编写脚本」补登，重试计数走 [惩罚机制](../../../../resistance/惩罚机制/惩罚机制.md)。
