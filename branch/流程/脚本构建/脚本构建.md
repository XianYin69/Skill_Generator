# 脚本构建

读取 tmp 素材，联网检索交互与逻辑操作，建立脚本描述与索引并编写、审核 Python 脚本。

## 约束关联

- 脚本须用**英文名**（`scripts/` 下），依赖须为 **MIT** 许可证。
- 失败计数走 [惩罚机制](../../../resistance/惩罚机制/惩罚机制.md)。
- 中间产物入 [过程链](../../../resistance/过程链存取/过程链存取.md)；残留由 [垃圾回收](../../../resistance/垃圾回收机制/垃圾回收机制.md) 兜底。
- **视觉 / 听觉交互**：用户如需通过视觉或听觉输入/交互，必须创建对应 `scripts/` 脚本（如 `vision_input.py`、`audio_input.py`）并在流程节点中显式调用；不得在流程外静默处理。

**入口节点**：[开始建立Script构建](开始建立Script构建/开始建立Script构建.md)
