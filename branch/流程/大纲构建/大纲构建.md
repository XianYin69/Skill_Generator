# 大纲构建（根节点）

根据需求经验和已有素材，构建可执行、可达、有兜底的初步流程大纲。

## 流程总览

```
建立大纲 → 审阅大纲 → 检查可执行 ──否──→ 记录错误 → 搜索方案 → 修改大纲 ──→ 审阅大纲
                              ↓ 是                                 （循环修复）
                         检查可达性 ──否──→ 记录错误
                              ↓ 是
                         检查兜底 ──否──→ 记录错误
                              ↓ 是
                         询问接受 ──不接受──→ 询问修改点 → 经验查询（重新收集）
                              ↓ 接受
                         生成大纲 → 标记完成 → 分支分析
```

## 节点

| 节点 | 类型 | 说明 |

| 检查可达性 | 决策 | 大纲能否到达每一个路径？是否存在无法到达的分支或孤立节点？... |
| 检查兜底 | 决策 | 是否具备兜底机制和错误回避机制？异常情况下能否降级或提示用户... |
| 记录错误 | 操作 | 记录当前步骤发现的错误点及上下文信息，写入 tmp/erro... |
| 搜索方案 | 操作 | 联网搜索与错误点相关的解决方案，参考同类 Skill 的处理... |
