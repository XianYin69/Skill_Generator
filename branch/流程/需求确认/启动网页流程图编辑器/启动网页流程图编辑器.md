# 启动网页流程图编辑器

操作节点。当用户需求模糊或功能描述不明确时，通过可视化编辑器让用户直接绘制流程图，输出 JSON 供后续流程消费。

## 步骤

1. 将 `scripts/flowchart_editor.py` 与 `scripts/flowchart_editor.html` 复制到目标 skill 的 `tmp/` 目录。
2. 执行 `python tmp/flowchart_editor.py --out tmp`（`--out` 指向目标 skill 的 tmp 目录）。
3. 提示用户在浏览器中绘制目标流程：添加节点（开始/结束·操作·判断）、连线、双击改名、Delete 删除。
4. 用户点击「导出 JSON」后，`tmp/flowchart.json` 生成，格式与 `flowchart/*.json` 一致。
5. 读取 `tmp/flowchart.json`，据此补全 `tmp/requirement.md` 的需求条目。
6. 清理编辑器进程，返回 [建立用户需求表](../建立用户需求表/建立用户需求表.md)。
