# 建立用户需求表

收集并记录用户需求，包括目标、功能、约束、期望输出，以及物理输入交互需求。

## 步骤

1. 记录用户目标、功能、约束、期望输出。
2. 若经过「判断是否需要物理输入交互」节点且标记为「是」，记录所需脚本清单：
   - 视觉：`vision_input.py`（摄像头/截图/图像识别）
   - 听觉：`audio_input.py`（麦克风/音频识别）
   - 网页交互：`browser_interaction.py`（浏览器自动化）
3. 写入 `tmp/requirement.md`。
4. 后续脚本构建阶段必须包含上述脚本。
