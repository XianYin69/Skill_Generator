# 沙盒交付

操作节点（仅沙盒模式）。生成 agent 提示词后、完成开发前的最后一步：把沙盒工作区交付到用户目标路径并删除沙盒。

## 操作

1. 检查工作区根是否有 `SANDBOX=1` 标记：无 → 非沙盒模式，直接进 [完成skill开发](../完成skill开发/完成skill开发.md)。
2. **询问用户目标工作区路径**（必须显式提供，不得默认或猜测）。
3. `python scripts/sandbox.py deliver --id <沙盒路径> --to <目标路径>` 先预览；向用户确认后加 `--yes` 执行复制。
4. 校验目标路径存在且非空 → `python scripts/sandbox.py clean --id <沙盒路径> --yes` 删除沙盒。
5. 交付未确认或复制失败 → **保留沙盒**，记中断（process_chain.py interrupt），禁止静默删除（见[沙盒机制](../../../../resistance/沙盒机制/沙盒机制.md)）。
