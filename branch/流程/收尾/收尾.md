# 收尾

遍历文件编写并审核提示词（正方/反方双链辩论）、编写自更新模块、编辑文档并执行 git 操作，**释放 tmp 到目标 skill 后在 `agent/` 子目录生成四种主流 agent/CLI 工具格式提示词**，完成 Skill 开发。

## 收尾必做：比对—释放—删除 tmp—生成 agent 提示词

1. `compare`：比对 `tmp/` 与目标 skill 差异（[self_update.py](../../../scripts/self_update.py)）。
2. 修正后 `release`：将 `tmp/` 内容释放覆盖到目标 skill。
3. `clean`：释放后删除 `tmp/`（见 [垃圾回收机制](../../../resistance/垃圾回收机制/垃圾回收机制.md)）。
4. `gen_agent_prompt`：调用 `gen_agent_prompt.py --target <目标skill>`，输出：① 目标根 `SKILL.md`（KiloCode YAML frontmatter + 系统提示词，≤50行）；② `agent/CLAUDE.md`、`agent/.cursorrules`、`agent/instructions.md`、`agent/agent_prompt.md`。
5. 自更新模块以[接口](../../../update/update.md)形式交付，供外部 skill 调用。
6. 沙盒模式：`sandbox.py deliver`（预览→`--yes` 复制）把沙盒工作区交付到用户指定目标路径，校验成功后 `clean --yes` 删除沙盒（见 [沙盒交付](沙盒交付/沙盒交付.md)）。

**入口节点**：[提示词编写开始](提示词编写开始/提示词编写开始.md)

## 节点

本步骤共 24 个节点（原 23 + 沙盒交付 1；含 3 提示词辩论 + 1 生成agent工具提示词），按流程图串联；各节点通过「决策分支」链接互相跳转。新增节点：
- 审核提示词 → 提示词正方链 → 提示词反方链 → 提示词辩论裁决 → 审核是否通过（新增正/反/裁决三节点）
- 收尾操作 → 生成agent工具提示词（写四格式到 agent/ 子目录）
- 生成agent工具提示词 → 沙盒交付（未指定目录时：复制到用户目标路径后删沙盒；常规模式直通）
