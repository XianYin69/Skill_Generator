# 知识库构建

检索相关领域文献，经正反辩论与普适性检验后建立文献—步骤索引，形成知识库。

## 来源与合规要求

1. 联网查询相关数据库与仓库，来源仅限：开放文献数据库、百科全书、权威论坛与博客、使用 MIT 许可证的仓库。
2. 下载到本地后**保留许可证与版权信息**（`.provenance.json` 随件）。
3. 对元数据**清洗并改造**为目标 skill 项目适合的形态（json/md/svg）。
4. 每条来源先按 [知识库信用评级](../../../references/知识库信用评级/知识库信用评级.md) 打分，C/D 级拒用或降级为线索。

配套脚本（MIT 依赖）：[knowledge_browser](../../../scripts/knowledge_browser.py)、[knowledge_download](../../../scripts/knowledge_download.py)、[knowledge_convert](../../../scripts/knowledge_convert.py)。

**入口节点**：[开始构建相关知识库](开始构建相关知识库/开始构建相关知识库.md)
