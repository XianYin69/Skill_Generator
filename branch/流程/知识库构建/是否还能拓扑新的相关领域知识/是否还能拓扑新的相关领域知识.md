# 是否还能拓扑新的相关领域知识

决策节点。判断知识树是否仍能拓扑出新的相关领域知识（即是否已到达不动点）。

## 判断依据

1. 已入库文献覆盖的领域节点是否仍有未探索的邻接相关领域。
2. 是否还存在可检索且信用评级 ≥ C 级（见 [知识库信用评级](../../../../references/知识库信用评级/知识库信用评级.md)）的相关来源尚未纳入。
3. 本轮检索相比上一轮是否新增了相关领域分支；无新增视为到达不动点。

## 决策分支

- 是（仍能拓扑新领域）→ [查找相关领域文献](../查找相关领域文献/查找相关领域文献.md)
- 否（到达不动点）→ [完成知识库构建](../完成知识库构建/完成知识库构建.md)
