# 流程（Process）

本目录存放 Skill_Generator 的执行流程细则，每个步骤独立成文件夹（或文件）。

## 两条独立路径

创建与修改是两条完全独立的流程，各自从「初始化」开始，互不交织。

### 创建流程

```
[初始化/](初始化/初始化.md) → [需求确认/](需求确认/需求确认.md) → [经验查询/](经验查询/经验查询.md) →
[大纲构建/](大纲构建/大纲构建.md) → [分支分析/](分支分析/分支分析.md) → [脚本构建/](脚本构建/脚本构建.md) →
[知识库构建/](知识库构建/知识库构建.md) → [约束编写/](约束编写/约束编写.md) → [整体审查/](整体审查/整体审查.md) →
[收尾/](收尾/收尾.md) → 完成
```

完成收尾后，创建流程结束。

### 修改流程

```
[初始化/](初始化/初始化.md) → [修改流程/](修改流程/修改流程.md) → 完成
```

修改流程独立运行，结束后标记「完成项目修改」。

## 全局机制与自更新接口

各步骤根 md 已接入 `resistance/` 五大机制约束（垃圾回收、上下文压缩、逻辑链、过程链存取、惩罚）与 `scripts/` 对应脚本；自更新以接口形式（[`update/update.md`](../../update/update.md)）在初始化挂载、收尾比对释放并删除 tmp。
