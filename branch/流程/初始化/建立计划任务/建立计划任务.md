# 建立计划任务

初始化时在技能目录内建立 `planned_tasks/`（计划任务声明目录），与 [加入MIT协议](../加入MIT协议/加入MIT协议.md) 同步汇入。

## 动作

1. 在工作空间根（及 `tmp/` 镜像，若存在）建立 `planned_tasks/`。
2. 写入 `README.md`（建立计划任务的流程与约束）与 `template.json`（条目模板）；模板取自 [`asset/planned_tasks/`](../../../../asset/planned_tasks/README.md)，缺失时脚本内置同构兜底。
3. 已有文件**不覆盖**（幂等跳过）。

## 指令

```
python -B scripts/init-planned-tasks.py --target <工作空间>          # 默认预览
python -B scripts/init-planned-tasks.py --target <工作空间> --yes    # 写盘
```

## 条目 schema（与 SMS 读取端一致·字段名不得改动）

`id / title / skill / input / schedule{mode,at,cron,every_min} / session{kind,key} / status / created / next_run / last_run / runs / notify / depends`

## 约束

- 一任务一文件，文件名 `pt-<skill>-<slug>.json`；原子写（临时文件＋替换）。
- `status` 仅 `pending/running/done/paused/failed`；时间一律本地 ISO。
- 到期由 **SMS 调度器**读取执行，执行记录挂到 `session.key` 关联链；**技能自身不得自行执行计划任务**；删除文件即注销。

## 分支

- 目标目录不存在 → 返回 `action=error`，不写盘，转 [建立沙盒](../建立沙盒/建立沙盒.md)。
- 已存在 `planned_tasks/` → `action=skip`，继续下一步。
