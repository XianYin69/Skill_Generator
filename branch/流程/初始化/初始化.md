# 初始化

在执行任何操作前，必须先完成初始化。创建与修改两条路径均从这里开始。

## 流程总览

```
读取目录 → 判断目录 → 检查tmp ──是──→ git操作
                      ↓ 否
                 记录目录 → 切换目录 → 检查切换 → 检查用户tmp
                                              ↓ 无
                                        建立tmp → git操作
                                                      ↓
                                                  标记完成
```

## 步骤节点

| 步骤 | 节点 | 说明 |
|---|---|---|
| 入口 | [读取目录](./读取目录/读取目录.md) | 读取当前目录 且 询问工作空间目录 |
| 判断 | [判断目录](./判断目录/判断目录.md) | 判断当前目录与用户指定目录是否一致 |
| 当前检查 | [检查tmp](./检查tmp/检查tmp.md) | 检查当前目录是否存在 tmp |
| 记录 | [记录目录](./记录目录/记录目录.md) | 记录用户指定目录 |
| 切换 | [切换目录](./切换目录/切换目录.md) | 切换到用户指定目录 |
| 切换验证 | [检查切换](./检查切换/检查切换.md) | 是否成功切换到用户指定目录 |
| 用户目录检查 | [检查用户tmp](./检查用户tmp/检查用户tmp.md) | 检查用户目录是否存在 tmp |
| 建立 | [建立tmp](./建立tmp/建立tmp.md) | 建立 tmp 及其他初始文件夹 |
| 版本控制 | [git操作](./git操作/git操作.md) | 未 git init 则自动 init；询问是否推送至远端 |
| 完成 | [标记完成](./标记完成/标记完成.md) | 标记初始化完成 |
