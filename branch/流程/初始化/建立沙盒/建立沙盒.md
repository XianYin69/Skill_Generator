# 建立沙盒

操作节点。用户**未指定目标工作目录**时进入：以固定路径下的沙盒作为临时工作区。

## 操作

1. 固定路径解析：env `SG_SANDBOX_HOME` → 用户缓存目录（Windows `%LOCALAPPDATA%` · macOS `~/Library/Caches` · Linux `~/.cache`）→ 用户根目录，统一在其下建 `Skill_Generator/sandbox/`（实现 [sandbox.py](../../../../scripts/sandbox.py)）。
2. `python scripts/sandbox.py create --name <技能名>` → 返回沙盒路径 `<固定路径>/<日期>-<技能名>`。
3. 以该沙盒为当前工作区继续，在沙盒根写 `SANDBOX=1` 标记（收尾「沙盒交付」据此识别）。

## 分支

- **成功** → [检查用户tmp](../检查用户tmp/检查用户tmp.md)（在沙盒内建 tmp 结构）
- **固定路径不可写** → 降级：向用户确认目标工作目录，转 [记录目录](../记录目录/记录目录.md)
